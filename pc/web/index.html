Tocca un file per l'anteprima. L'icona di condivisione lo porta nelle app dell'iPad (Salva su File, Foto, AirDrop…). I file si tolgono solo cancellandoli dalla cartella sul PC.

    Inviare dalle altre app dell'iPad

    Le app web non possono comparire nel menu Condividi: si usa un Comando rapido, una volta sola.

    1. Tocca Copia indirizzo qui sotto.
    2. Apri l'app Comandi → + → nome: Invia a Schermo Esteso.
    3. Tocca ⓘ e attiva Mostra nel foglio di condivisione.
    4. Aggiungi l'azione Ottieni contenuti dell'URL: incolla l'indirizzo, Metodo POST, Corpo richiesta Modulo, aggiungi un campo File con chiave file e valore Input comando.
    5. (Facoltativo) aggiungi Mostra notifica: «Inviato al PC».

    Da qualsiasi app: Condividi → Invia a Schermo Esteso. L'indirizzo contiene la chiave di questo dispositivo: non condividerlo.

    Connessione sicura (certificato del PC)

    Serve una volta sola per dispositivo: toglie l'avviso di Safari, cifra la connessione e attiva la condivisione.

    1. Scarica il certificato e tocca Consenti.
    2. Impostazioni → Profilo scaricato (o Generali → VPN e gestione dispositivi) → Installa.
    3. Impostazioni → Generali → Info → Impostazioni attendibilità certificati: attiva Schermo Esteso - certificato del PC.

    Il certificato vale solo per la rete di casa o dell'hotspot: non può essere usato per altri siti.

    Schermo Esteso

    Questo dispositivo è nuovo: inserisci il PIN di 6 cifre che compare ora sul PC. Serve solo la prima volta.

    Safari ha mostrato un avviso di sicurezza? Installa il certificato del PC (istruzioni nel menu → File).
